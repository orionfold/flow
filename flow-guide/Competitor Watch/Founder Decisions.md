# Founder Decisions

Use act, investigate, watch or ignore after reviewing the evidence. An empty decision is intentional. Record a contrary observation as well as the signal that caught your attention.

| Question | Current disposition | Evidence to inspect | Small experiment | Revisit trigger |
| --- | --- | --- | --- | --- |
| Does a recurring task justify automation? | Undecided | Summation and Raycast workflow contracts | Repeat one customer task and record checking effort | A user repeats the task twice |
| What must a draft isolate? | Undecided | Lovable draft and shared-data behavior | Map which changes affect live data | A proposed edit touches shared input |
| Where does useful AI output go next? | Undecided | Raycast retention observations | Reopen last week's result and correct one detail | Work is copied into another tool |
| Which pricing unit is understandable? | Undecided | Dated Raycast plans and allowances | Ask a prospective user to explain expected monthly exposure | Allowances or usage pricing change |
| Could a small existing tool solve the need? | Undecided | Glaze and Bolt public material | Compare one concrete task using an available alternative | Building exceeds one experiment |

## Decision record

For each decision, add its date, chosen response, source links, rationale, counterevidence and next check. The model may help expand the context, but your disposition stays yours.
