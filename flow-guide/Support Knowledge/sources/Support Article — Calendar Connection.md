# Confirm the connected calendar

**Fictional Beacon Scheduling help article.** This is not an instruction for Flow or any real external service. Current means approved within the sample story, not published by a Flow job.

Check the calendar name and account before expecting an event to appear. If two calendars have similar names, compare the account as well. After a reconnect, verify one known test event before changing more settings.

| Check | What to confirm in this fictional workflow |
| --- | --- |
| Calendar identity | Compare both calendar name and account |
| Similar names | Select the intended calendar using its account context |
| Reconnected calendar | Verify one known test event before changing more settings |
