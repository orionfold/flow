# Review what your agents wrote

**For Claude Code and Codex users.** “My agents write documents in a terminal. I want to read them, approve them, and know who changed what.”

| For | What lasts | Needs |
| --- | --- | --- |
| Claude Code and Codex users | Trust, Lower cost | Free to start |

1. **Point your agent at a folder open in Flow.** Run Claude Code or Codex in this folder, or from Flow on the subscription you already have. The [Agent Brief](Agent%20Brief.md) tells it the rules.
2. **Keep or revert each change it made.** Its edits arrive in **Review Changes**, marked with the agent’s name; **Keep** or **Revert** each part.
3. **History names the writer of every version.** **History** shows who wrote each version, and the receipt shows the run was *Included* in your plan.

**What lasts:** you approve every change an agent makes, and you pay no second AI bill for it.
