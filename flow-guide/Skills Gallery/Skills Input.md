## Edit the input, then inspect the result

Use **View ▸ Edit Table** on this document, change Dark mode's value from 3 to 7 and its quadrant to Quick win, then save. Open [[Skills — Living Example]] and choose **Settings ▸ Jobs ▸ Run all Jobs**. The map moves Dark mode up, and the summary counts two quick wins.

Keep the heading **Initiatives** and one table beneath it, with the columns `initiative`, `value`, `effort` and `quadrant`. The quadrant is yours to name: the refresh counts the rows you call a Quick win rather than deciding for you.

The table is authored input, and the refresh never overwrites it. If you rename the heading or a column, update [[Skills Refresh]] and the chart in [[Skills — Living Example]] together.
