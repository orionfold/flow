# Team Working Agreement

**A fictional team handbook to adapt**

## Keep the evidence beside the decision

Use one folder for the review, source records and working notes. Give each decision an owner and a date. Change the source once, refresh the exhibit, then revisit any narrative that depends on it.

| Practice | Why it helps |
| --- | --- |
| One Quarterly Close source | Totals can be recomputed consistently |
| A named decision record | Separate evidence from approval |
| Local assets and unique page names | The folder can be copied intact |
| Dated notes on uncertainties | Future readers can see what was unknown |

## Working in Flow

Use Search to find an earlier passage. Compare the close with the draft in two panes. Ask Agency for a summary or a proposed revision, then inspect its changes before applying. Open History for saved document versions.

The data refresh runs locally from the saved definition. A model action uses the route shown by Flow; choose a local route if this folder must stay on the Mac. No job in this example sends messages or publishes a report.
