# Leave rented notes

**For people leaving Notion.** “I want to own my notes, work offline, and use AI only when I ask.”

| For | What lasts | Needs |
| --- | --- | --- |
| Coming from Notion | Ownership, Lower cost | Free to start |

1. **Export from Notion; add the folder.** Notion’s Markdown export opens in place; nothing is imported into a database. See [Using Flow ▸ Plain text, with structure](x-flow://handbook/Using%20Flow#Plain%20text%2C%20with%20structure).
2. **Pick a model: on this Mac or your own key.** **Smart Routing** chooses between a model on this Mac and the keys you already have, or you pin one. See [Using Flow ▸ Use the right model for the work](x-flow://handbook/Using%20Flow#Use%20the%20right%20model%20for%20the%20work).
3. **Every AI edit is a change you approve.** Run one action and keep or revert what it proposes; [Files Flow Writes](x-flow://handbook/Files%20Flow%20Writes) lists everything Flow ever writes.

**What lasts:** your notes stay readable without Flow, and you pay for AI only when you use it.
