# Conduct beautiful documents

This folder is not a tour. It is a working set of documents — a business review
that went to a board, the research underneath it, an investment memo, a client
proposal, a press release, a product brief — plus a complete catalogue of every
chart Flow draws.

Read them as documents. The features are all in here, but they are load-bearing
rather than on display.

![A quiet desk, mid-work](assets/quiet-desk.jpeg)

*Everything in this folder is an ordinary Markdown file. Nothing here needs Flow to open.*

## Start with the two galleries

[[Document Gallery]] is the template set: twenty-five kinds of document a
knowledge worker actually has to produce — project plans, meeting notes, board
letters, sales reports, a performance review, a resume, a trip planner — each
one written out in full here, each saying what it is for and what shape it
takes. Copy one and edit over it.

[[Visualization Gallery]] does the same for pictures: every chart and diagram
Flow draws in place, offline, from plain Markdown — thirty-six of them, each
naming the source material that gets you there.

## Three words, and where to test them

The promise is *conduct beautiful documents with AI agency built in*. Each word
is answerable in this folder rather than in prose about the folder.

**Conduct** — you direct; the work gets done. [[Quarterly Business Review]] was
framed as an outcome, not typed a line at a time, and the direction is still
legible in [[How We Decided]].

**Beautiful** — [[Visualization Gallery]] is the widest test and
[[Annual Operating Review]] the deepest. [[Revenue Dashboard]] is the honest
one: Markdown has no layout, so a real dashboard is out of reach, and that
document says exactly where the gap is.

**With your approval** — nothing here changed without someone saying yes.
[[How We Decided]] shows the gate as the feature it is.

## This folder is yours

Flow created it inside its own application-support directory and will not touch
it again. Edit these documents, rename them, delete the ones you do not want —
they are ordinary Markdown files in an ordinary folder, and Flow treats them
exactly like any other folder you open. If you edit a document here, Flow leaves
your version alone. If you delete one, it stays deleted.

To keep a copy somewhere you will find it later, drag the folder out in Finder,
or use **Reveal in Finder** on the folder in the sidebar. To move it somewhere
else for good, use **Settings ▸ Flow System ▸ Change Location…**, which moves
this folder and everything you have done to it.

## Where Flow is going

Today Flow writes Markdown, and every document here renders correctly in any
other Markdown editor. Documents that run as small applications, and a Flow that
improves your work while you are away, are the direction — not what this build
does.
