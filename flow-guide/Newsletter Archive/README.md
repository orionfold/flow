# The weekly issue, then the book

**For creators.** “I want my newsletter to be mine, and one day to be a book.”

| For | What lasts | Needs |
| --- | --- | --- |
| Creators | Ownership, Saves time | Flow Pro, Flow Publish |

1. **Dictate the issue; draft it with Expand.** Speak the first draft with **Dictation** (⇧⌘D), then **Expand with Sources** fills it out from your notes, as changes you review.
2. **Describe Picture writes the alt text.** **Describe Picture**, on a picture’s actions, gives every picture in an issue a description you can edit, so the archive is readable by everyone.
3. **Collect the issues into an EPUB.** **Publish** turns the `issues/` folder into a book with contents and a cover.

**What lasts:** every issue is a plain file you own, and the year’s issues are one book.
