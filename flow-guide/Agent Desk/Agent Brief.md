# Agent Brief

**The brief an agent works from.** Point Claude Code or Codex at this folder, or run one from Flow on *Your Claude subscription* or *Your Codex subscription*, and ask it to work through the tasks.

| Rule | Why |
| --- | --- |
| Write only inside this folder | Every change then arrives in Review Changes |
| One task per change | You keep or revert each part on its own |
| Cite the file you read | The review shows what the claim rests on |
