# Workspace Library

## Choose the work, then copy the folder

Every living workspace is a folder with a useful main document and the local files that support it. Copy the entire folder, add the copy to Flow, and follow **Make it yours**. You do not need to copy the whole Guide.

## What travels with the folder

The main document, supporting pages, local data, definitions and images are packaged together. A workspace may name optional public web sources; check its Jobs before enabling them. Optional Overnight notes require a configured local model. Neither is needed to read the bundled example.

## A document can take several forms

Read the business review as an executive brief, the shareholder letter as an editorial narrative, the legal matter as a chronology, the supplier review as a comparison, and the travel plan as a journal. Use the form the work needs. [[Charts Gallery]] is the visual reference; [[Using Flow]] explains the tools.
